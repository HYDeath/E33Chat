# TrChat + E33Chat Fabric 2.4.15 compatibility build

This branch produces a single Bukkit `TrChat` Jar targeting Java 21 bytecode. Install it on each Paper/Folia backend; do not install a server-side E33 Fabric/Forge mod or a Velocity companion. E33Chat Fabric 2.4.15 clients use `e33chat:*` plugin messaging; unmodded clients receive ordinary TrChat chat. Forge's `e33chat:main` protocol is not supported.

## Setup

1. Build with Java 21: `./gradlew :plugin:build`. Install `plugin/build/libs/TrChat-2.5.3+e33compat.16.jar` on each backend. Remove older TrChat Jars so the server does not load the wrong version or duplicate plugin name. Restart each backend, then update the client to `e33chat-Fabric-1.21.11-2.4.15+compat.1.jar` or the matching 26.x build and restart Minecraft. Install the backend plugin first: the client advertises `e33chat:downstream_v3`.
2. In each backend's TrChat `settings.yml`, set `Redis.enabled: true` and the same Redis host/port/credentials. The bridge reads PlaceholderAPI `%server_name%` on the sending backend for the source server prefix; `e33.server-id` in TrChat's Bukkit config remains the fallback. No proxy plugin is required.
3. Optional PlaceholderAPI plus CMI permits `%cmi_user_display_name%` resolution. Without it, the player's Bukkit display name and finally account name are used. Duplicate display names are not automatically resolved for private messaging or mention targeting.
4. Set `trchat.admin` for users allowed to open `/e33chat gui`, edit templates or save the E33 server-config screen. The server rechecks this permission on incoming save packets.

The E33 bubble sender defaults to TrChat's `%trchat_displayname%`, so it matches the name used by the default TrChat channel formatter. The floating CustomNameplates tag is only a fallback. An optional Bukkit config entry `e33.sender-format` supports `{display_name}`, `{server_name}`, `{title}`, and `{player_id}`; for example `{title}{player_id}`. `{display_name}` already includes the PlayerTitle title when available. The E33 client adds the source server prefix separately. TrChat channel formats can use `%trchat_server_name%`, `%trchat_title%`, and `%trchat_player_id%` too. When `%server_name%` is unavailable, set a distinct `e33.server-id` on each backend.

The existing TrChat `TrChatEvent`, `Channel` and package names remain. Redis stores the public-history ring (50 messages), E33 settings and active aliases. Public messages and metadata are fanned out via Redis. Redis downtime falls back to local chat; cross-server features are unavailable until recovery. This compatibility build does not accept local image uploads.

Automatic links are HTTP/HTTPS click-and-hover components only. This build does not fetch pages or render rich cards. CustomNameplates integration attempts to reuse its native TrChat provider when the plugin loads; if it is absent or unavailable, one short-lived TextDisplay bubble is shown for local public chat. No fallback bubble is created for cross-server senders or private chat. There is no bundled 26.3 port of CustomNameplates. WarZHongBao is not included.
Private-channel events set `forward=false`, so the native TrChat bubble provider does not display private messages.

The upgraded E33 client negotiates one `downstream_v3` receiving channel for the bridge's 13 S2C message types. The first byte identifies the original payload type. The 2.4.15 client accepts TrChat's legacy seven-field history rows and server-settings screen packet while native Fabric servers use the new group-aware formats. The plugin accepts both old and new server-settings save packets, keeping its stored settings format unchanged. TrChat reports E33 groups disabled and does not implement upstream E33 group chat; changing that switch in the client's settings cannot enable server-side groups. The semantic public/private message includes UUID, styled body, quote, mention UUIDs and optional CustomNameplates decoration. Cross-server private messages use Redis and are not stored offline; a detected Redis outage produces a send-failure notice. Exact visual parity of every legacy TrChat transformer is not guaranteed. The optional DiscordSRV chat listener is excluded from this single-Jar build while its direct API dependency is removed. The compatibility client's 30 KiB media chunks are intended for the plugin bridge, not a legacy Fabric server mod.

## Validation status

Compilation and packaging have been checked locally, and the E33 codec has golden-byte and malformed-length tests. Paper 26.3 alpha API signatures used by TextDisplay/entity scheduling were inspected statically. At the user's request, no Minecraft EULA was accepted and no server was launched. A Minecraft launch matrix on Paper/Folia 1.21.x/26.1.2/26.2/26.3, dual-node Redis, IME/mixin smoke tests and CustomNameplates runtime verification remain necessary before claiming production certification. The Gradle test worker in the local Chinese-path checkout cannot start, so compilation of tests and a direct protocol roundtrip are verified, but a green Gradle test run is not yet available.
